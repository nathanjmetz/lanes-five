# Music

Nathan's own songs and theme music go here (2026-11-15: "Reserve a space for music to go later once I create music and theme songs").

To add a song:
1. Put the file here, for example `public/music/theme.mp3` (MP3 or OGG, ideally under 5 MB).
2. Add a line to `src/music.js`, for example `{ id: 'theme', name: 'Hearth Lane theme', file: '/music/theme.mp3' }`.
3. It shows up in Menu → Settings → Music → Song, for every player.
